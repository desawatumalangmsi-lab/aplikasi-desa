Drive belum terhubung — foto tersimpan di perangkat ini.
Cara menyiapkan Google Drive (sekali saja)
1) Buka Google Cloud Console → buat proyek → aktifkan Google Drive API. 2) Credentials → Create OAuth client ID → tipe Web application; pada Authorized JavaScript origins isi alamat tempat aplikasi ini dibuka (https://…, bukan file lokal). 3) Salin Client ID, lalu klik "Hubungkan Google Drive" dan tempel. Foto masuk ke folder "Dokumentasi Desa …" di Drive Anda; aplikasi hanya dapat melihat file yang dibuatnya sendiri.
Isi laporan diambil otomatis dari Perencanaan (kegiatan, output, pagu) dan Pencairan (realisasi s.d. akhir periode). Volume realisasi dihitung proporsional terhadap realisasi anggaran, dan dapat diubah langsung pada kolomnya (mis. "6" dan "Orang x Bulan"). Foto disimpan di browser perangkat ini (tidak ikut Ekspor Cadangan/Data Bersama).
